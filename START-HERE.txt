EVIDENCE / VALIDATION
Demo logs are in .lab/demo-TIMESTAMP.txt. They record actual results; inspect every error.
Wireshark client filter: dns || tcp.port == 8443
A cached success is not backup DNS proof. Capture a fresh query to Mac 4 with Mac 1 DNS stopped.
DNS TTL does not migrate existing TCP connections.
Use only trusted HTTPS for final demonstration; no curl -k.
Firewall script refuses if required parent anchor is missing. Do not force global pf reloads.
Save rollback proof. Restore original client DNS settings from .lab/original-dns.txt.
If original settings were automatic: sudo networksetup -setdnsservers Wi-Fi Empty

KNOWN CACHE CORRECTNESS ISSUE IN ORIGINAL CODE

Before a rigorous cache demonstration, make cached response bodies identical or use distinct validators.
The shared cache body is corrected in this prepared package; X-Backend still identifies each origin.
